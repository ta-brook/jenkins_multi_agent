# Agent Workflow

- After completing any change to the repo (code, docs, config), commit the
  changes with a concise message and push to `origin/main`.
- Do not wait to be asked to commit or push; do it as the final step of each
  completed task.
- Before committing, review `git status` and `git diff` so only intended files
  are staged; never commit secrets.
- If the task is explicitly read-only or the user says not to push, skip this.
